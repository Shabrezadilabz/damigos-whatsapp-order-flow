# D'amigo's — WhatsApp Order Flow

Explainer site for the **WhatsApp food-delivery architecture**: scan parcel QR → order in chat → UPI → kitchen → rider. **0% commission.**

Same Hospitality Modernism theme as the main D'amigo's brand site.

## Live

- GitHub: (this repo)
- Vercel: after deploy

## Run locally

```bash
npm install
npm run dev
```
